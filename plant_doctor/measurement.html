Open Plant Doctor — Demand Test in Google Analytics

Demand signals

Signup rate = sessions with a confirmed signup ÷ landing sessions. plant_waitlist_success is a key event counted once per session, without a monetary value. It fires only after Firebase confirms a save. Also compare signup success to form views to see how well the coming-soon message converts. Firebase stores the email list; GA4 receives no email addresses. Normalize and deduplicate emails before a launch campaign. These are submitted addresses, not verified email ownership.

Store-intent rate = sessions with a store-button tap ÷ landing sessions. Compare the five designs using the same ad creative, audience, placement, device mix and time window. Analyze App Store and Google Play choices separately as well as combined. Do not use raw tap counts as unique people.

plant_download_intent is a GA4 key event counted once per session, with no monetary value. The site sends it once per page load after the first App Store or Google Play tap. Repeated taps remain available in plant_store_click. Care-plan taps have their own event and do not inflate the store-intent conversion.

TikTok conversion setup

Pixel: DBESNJRC77U4J2JQDU50 (PlantAI Landing). The standard Lead event fires once per page only after Firebase confirms an email signup. Select this pixel and Lead / Form submission as the website conversion event in TikTok Ads Manager. The site also sends PageView, ViewContent and the custom DownloadIntent event. DownloadIntent is a store-button tap, not an install. There is no purchase event or monetary value.

In Events Manager, open the pixel’s Test Events tab and generate a test visit for https://bestme.mobi/plant_ai/?analytics_debug=1&tiktok_test=1. Follow TikTok’s generated test link or QR code, then submit a synthetic email. Expect PageView, ViewContent and Lead after the success screen. Invalid emails or failed database saves must not produce Lead. This URL uses the separate Firebase QA list and excludes GA4 reports. Plain preview=1 links never load the pixel; ordinary analytics_debug=1 visits also suppress it.

Keep a unique utm_content value per video version. The pixel also receives it as ad_version; GA4 and Firebase retain the same campaign tag. The Events API token is not used in this browser-only integration and is not published. Do not add an Event Builder Lead rule to the submit button: that would count attempts before successful saves and could duplicate manual events.

Reporting

Use GA4 Explore with Landing variant, Store choice, CTA placement, Feature, Scroll depth and Browser context. Add Sessions, Total users, Event count and Session key-event rate. Filter the key event to plant_waitlist_success for signups or plant_download_intent for store intent. Use Session source/medium, Session campaign and Session manual ad content for ad attribution. Feature visible time is a registered millisecond metric.

For each feature, compare unique viewers, care-plan/store intent, and visible time. Exposure is affected by scroll order; this does not by itself prove a causal preference. Compare store choices using users or sessions, since someone can tap both stores.

Review and privacy

?preview=1, local previews and gallery visits send no analytics. GPC and the local opt-out are respected. Google advertising storage, Google personalization and Google signals are disabled. TikTok Pixel is configured separately as described in the privacy notice. The optional launch form stores emails in Firebase, separately from analytics. No email addresses, user IDs, uploads or server-side conversion copies are sent to GA4. Successful signups are measured only after Firebase confirms the write. Only approved UTM fields are retained in reported page URLs; referrer paths and arbitrary query parameters are excluded.

Ad blockers, privacy settings and browser restrictions can reduce measured visits. Custom definitions and normal reports can take 24–48 hours to populate. Realtime/DebugView are for implementation checks. An analytics-only button measures intent; it is never reported as an install.
